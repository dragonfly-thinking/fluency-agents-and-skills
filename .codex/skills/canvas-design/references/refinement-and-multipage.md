# Refinement Pass & Multi-Page Option

Read this after the first canvas render — the refinement pass — and whenever the user asks for more than one page.

## The refinement pass (always do this)

The first render is a draft. Treat every piece as needing a second pass toward "pristine — as if about to be displayed in a museum" before you hand it over.

To refine, **do not add more graphics.** The instinct to call a new function or draw a new shape is almost always wrong at this stage. Instead, refine what's already there and make it extremely crisp — tighter composition, more cohesive color, better optical alignment, cleaner spacing — while respecting the design philosophy and the principles of minimalism entirely.

When you feel the urge to add something, stop and ask instead: *"How can I make what's already here more of a piece of art?"* Go back to the code and polish. A more cohesive composition beats a busier one every time.

## Multi-page option

When the user asks for more than one page, create additional pages along the same lines as the design philosophy — but each distinctly different as well. Bundle them in the same `.pdf`, or output many `.png` files.

Treat the first page as a single page in a whole coffee-table book waiting to be filled. Make the next pages unique twists and echoes of the original — variations on the movement, not repeats of it. Have them almost tell a story, tastefully. Exercise full creative freedom while keeping the whole set unmistakably one body of work.
